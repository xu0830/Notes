## HTTP 1.0、1.1、 2.0有什么区别

1.0  短连接 （100 次请求，100次 tcp 握手和挥手）

1.1  长连接 （100 次请求，1 次 tcp 握手挥手）

2.0  长连接 + IO多路复用模型 （五大模型之一）

## RPC 和 http 有什么区别

### 性能

主要差别在序列化和反序列化

rpc 通过 thrift 二进制传输

http json、html文本，序列化更消耗性能

### 传输协议

rpc 基于 tcp 或 http

http 只能是 http

### 负载均衡

rpc 自带负载均衡

http 需要额外配置

### 传输效率

rpc 报文较小

http 头部信息过多

### 通知

rpc 自动通知

http 事先通知，自行修改 nginx 其他配置或者
