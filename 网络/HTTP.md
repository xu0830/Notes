## HTTP

|    特性     |      HTTP/1.1      |        HTTP/2        |   HTTP/3    |
| ---------- | ------------------ | -------------------- | ----------- |
| 传输层      | TCP                | TCP                  | QUIC (UDP)  |
| 数据格式	 | 文本	              | 二进制帧              | 二进制帧     |
| 连接复用	 | 有限（Keep-Alive） | 多路复用              | 增强多路复用 |
| 头部压缩	 | 无                 | HPACK                | QPACK       |
| 队头阻塞	 | 存在（请求/响应）   | TCP 层存在           | 彻底消除     |
| 服务器推送	 | 不支持             | 支持                 | 支持         |
| 0-RTT 建连  | 否                 | 否                   | 支持         |
| 默认加密	 | 否                 | 否 （但行业要求 TLS） | 强制加密     |
