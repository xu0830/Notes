# 委托

委托是一种特殊的类，一种数据类型

类型安全的函数指针，定义了方法的签名，

允许将方法作为参数传递，实现回调的基础

使用不当有可能造成内存泄漏，导致程序性能下降（委托类不能释放）

```
// 1. 声明委托类型
public delegate void MyDelegate(string message);

// 2. 创建委托实例
MyDelegate del = Method1;

// 3. 调用委托
del("Hello");
```




##  多播委托

+=

忽略之前函数的返回值，最后执行的目标函数所返回的结果当成整个委托的结果

异常会中断调用链

#  事件

基于委托的发布-订阅机制，允许类或对象通知其他类或对象发生了特定事情

是委托的封装，只能在声明类中触发

订阅模式，外部只能通过+=和-=订阅或取消订阅

观察者模式

防止外部直接调用或重置委托

```
// 1. 声明事件
public event EventHandler MyEvent;

// 2. 触发事件
MyEvent?.Invoke(this, EventArgs.Empty);

// 3. 订阅事件
obj.MyEvent += HandleEvent;
```

```
private EventHandler _myEvent;

public event EventHandler MyEvent
{
    add 
    {
        Console.WriteLine("添加事件处理程序");
        _myEvent += value;
    }
    remove 
    {
        Console.WriteLine("移除事件处理程序");
        _myEvent -= value;
    }
}
```

## 原则

* 谁订阅，谁负责取消订阅

* 在Dispose()或对象生命周期结束时取消订阅

## 弱事件模式

解决事件引起的内存泄漏

需要注意取消订阅，否则可能导致内存泄漏

### 实现

#### 弱引用事件

使用 WeakReference 类型，弱引用类型

如果一个对象只被弱引用关联，则垃圾回收器会回收它

强引用： 一个对象正被程序使用，应用程序对该对象有强引用

比普通事件多约10-20%的性能开销

适用于低频事件，高频事件需评估

```
public static class WeakEventManager
{
    private static readonly List<WeakReference<EventHandler>> _handlers = new List<WeakReference<EventHandler>>();
    
    public static event EventHandler Event
    {
        add => _handlers.Add(new WeakReference<EventHandler>(value));
        remove => _handlers.RemoveAll(wr => wr.TryGetTarget(out var handler) && handler == value);
    }
    
    public static void RaiseEvent()
    {
        foreach (var weakRef in _handlers.ToList())
        {
            if (weakRef.TryGetTarget(out var handler))
            {
                handler.Invoke(null, EventArgs.Empty);
            }
            else
            {
                _handlers.Remove(weakRef);
            }
        }
    }
}
```
### 相互订阅导致内存泄漏

```
public class ServiceA
{
    public event EventHandler WorkDone;
    
    public void DoWork()
    {
        // ...工作完成后
        WorkDone?.Invoke(this, EventArgs.Empty);
    }
}

public class ServiceB
{
    private readonly ServiceA _serviceA;
    
    public ServiceB(ServiceA serviceA)
    {
        _serviceA = serviceA;
        _serviceA.WorkDone += OnWorkDone; // 相互引用
    }
    
    private void OnWorkDone(object sender, EventArgs e) { }
}
```

### 静态事件

`public static event EventHandler ApplicationStarted;`

静态事件会保持对订阅者的引用，可能导致订阅者无法被垃圾回收

应在对象的析构函数中取消订阅

```
public class LeakyComponent
{
    public LeakyComponent()
    {
        // 错误：实例方法订阅静态事件，会阻止实例被回收
        Logger.LogMessage += this.InstanceHandler;
    }
    
    private void InstanceHandler(object sender, string message) { }
}
```

#### 注意多线程安全

* 订阅/取消事件可能存在竞争，多个线程同时修改事件

* 空引用异常

* 事件处理程序执行顺序不一致，不同线程看到的处理顺序可能不同
 
##### ReaderWriterLockSlim 优化

轻量级锁，允许多个线程同时读取数据，但只允许一个线程写入数据，从而提高了并发性能

```
public static class OptimizedThreadSafeEvent
{
    private static readonly ReaderWriterLockSlim _rwLock = new ReaderWriterLockSlim();
    private static event EventHandler _myEvent;
    
    public static event EventHandler MyEvent
    {
        add
        {
            _rwLock.EnterWriteLock();
            try
            {
                _myEvent += value;
            }
            finally
            {
                _rwLock.ExitWriteLock();
            }
        }
        remove
        {
            _rwLock.EnterWriteLock();
            try
            {
                _myEvent -= value;
            }
            finally
            {
                _rwLock.ExitWriteLock();
            }
        }
    }
    
    public static void RaiseEvent()
    {
        EventHandler handlers;
        _rwLock.EnterReadLock();
        try
        {
            handlers = _myEvent;
        }
        finally
        {
            _rwLock.ExitReadLock();
        }
        handlers?.Invoke(null, EventArgs.Empty);
    }
}
```

#### 静态事件与实例事件对比

|     特性     |      静态事件       |        实例事件         |
| ----------- | ------------------ | ---------------------- |
| 关联对象     | 类                  | 类的实例                |
| 访问方式     | 通过类名访问         | 通过实例访问            |
| 生命周期     | 应用程序域生命周期   | 实例生命周期            |
| 内存泄漏风险 | 更高(需显式取消订阅) | 较低(实例销毁时自动取消) |
| 典型用途     | 全局通知、跨组件通信  | 对象状态变化通知         |	
				

# 委托和事件对比

|    特性     |         委托         |          事件          |
| ---------- | -------------------- | ---------------------- |
| 本质        | 类型安全的函数指针     | 特殊封装的委托字段       |
| 调用权限	 | 可在任何地方调用	    | 只能在声明类中触发       |
| 订阅方式	 | 可直接赋值(=)         | 只能使用+=/-=操作符     |
| 多播支持	 | 是                   | 是                     |
| 典型用途	 | 回调机制、通用函数指针 | 实现观察者模式、组件间通 |
| 封装性	     | 低                   | 高                     |
| 空引用检查	 | 使用?.Invoke()语法糖  | 使用?.Invoke()语法糖    |
